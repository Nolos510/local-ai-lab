# Dashboard Product Loop

The dashboard product loop starts with a source packet, creates a radar
candidate, records security review state, captures a benchmark artifact,
imports dashboard CSVs, and ends with a keep, watchlist, retest, or skip
decision. Candidate-only records must remain visually and logically separate
from evaluated model scores.

Demo fixtures and installed runtime inventory are not proof that a model is
ranked or installed for evaluation. Ranked models come from confirmed benchmark
imports.
