# PRD to Tasks

Use this skill to turn product intent into buildable work.

## Workflow

1. Identify the user goal, core flows, constraints, and non-goals.
2. Split the work into small tasks that can be implemented and reviewed independently.
3. Write acceptance criteria in observable terms.
4. Call out dependencies, decisions, and risks.
5. Keep the task list practical for the current repo and team size.

## Output

Use `templates/tasks.md` when the task breakdown should be saved.
