# Code Review

Use this skill for review-first engineering feedback.

## Workflow

1. Inspect the changed files, nearby code, and relevant tests.
2. Prioritize correctness, regressions, data loss, security, and test gaps.
3. Report findings before summaries.
4. Include file and line references whenever possible.
5. Keep suggestions actionable and avoid style-only comments unless they block maintainability.

## Output

Use `templates/review.md` when preparing a durable review note.
