## Validation

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e ".[dev]"
python -m pytest -q
```

Result:

- Editable install succeeded for `ai-lab-os==0.1.0`.
- Tests passed: `10 passed`.
- Use `python3` to create the venv and `python` inside the activated venv.
- `pytest` is intentionally installed through the `dev` extra, not as a runtime dashboard dependency.
- In Codex sandbox runs, pip may need network approval if build tools or pytest are not cached locally.

The dashboard still runs through:

